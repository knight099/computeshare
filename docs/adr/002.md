# ADR-002: Outbound gateway protocol

Status: accepted for staged implementation.

## Decision

Use TLS 1.3 at the public reverse proxy and versioned JSON over an agent-initiated WebSocket. Heartbeats are 15 seconds, suspect after 45 seconds; reconnect uses capped exponential backoff and cryptographic jitter. Reauthenticate with device-key proof on reconnect.

## Consequences and current limitations

The M1 gateway is a single process; fleet-wide connection routing and distributed rate limits belong to M6.
