# ADR-008: Durable state versus ephemeral presence

Status: accepted for staged implementation.

## Decision

PostgreSQL owns users, consent, registry, last-seen timestamps, authentication challenges, credential hashes and audit events. Redis is reserved for ephemeral connection routing/rate limits. Initial WebSocket routing is process-local.

## Consequences and current limitations

No accounting authority is assigned to Redis. HA requires shared revocation notifications in M6.
