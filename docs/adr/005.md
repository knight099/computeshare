# ADR-005: Technical usage evidence without financial accounting

Status: accepted; financial journal proposal superseded by the owner's 2026-11-17 [scope decision](../product-scope.md).

## Decision

Record successful output validation and technical usage atomically with completion. One durable record per job and attempt contains identity, immutable policy snapshot, configured logical iterations, server-observed duration and optional host-reported CPU/memory. First observations are preserved; replay cannot create a duplicate or replace a report.

Telemetry stays explicitly untrusted even when within bounds. Out-of-policy claims are retained as rejected, and old agents may report no telemetry. A validated output is not attestation of physical CPU time. Authenticated scoped history, SDK pagination and durable metadata events support company integrations.

## Consequences

No credit policies, balanced financial journals, prices, balances, settlement, payments or payouts belong in the framework. Companies own any commercial interpretation in their separate systems. Availability alone is not completed work; plausible agent metrics are not fraud-proof evidence. Security review and broader runtime/operational gates remain mandatory before claiming production readiness.
