# ADR-003: Leases and idempotent transitions

Status: accepted for staged implementation.

## Decision

PostgreSQL transactions and attempt epochs fence state changes. At-least-once dispatch uses NATS JetStream; accepted completion and credit settlement have unique idempotency keys. Use a transactional outbox when job events are introduced in M2/M3.

## Consequences and current limitations

Exactly-once execution is not promised. Job execution is disabled in the enrollment release.
