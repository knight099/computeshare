# ADR-009: S3 artifacts and development storage

Status: accepted for staged implementation.

## Decision

Artifact interfaces target S3-compatible storage with content hashes, immutable manifests, signed transfers and classification. Development uses SeaweedFS 4.53: tested official MinIO registry references were unavailable in this environment. Readiness performs authenticated SigV4 ListBuckets, never a mock response.

## Consequences and current limitations

This is a development storage substitution from the master document. Artifact upload/signature lifecycle arrives in M2/M5. Do not treat development storage credentials as production least-privilege policy.
