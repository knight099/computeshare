# ADR-004: Allowlisted execution and runtime gate

Status: accepted for staged implementation.

## Decision

M2/M3 execute only compiled-in deterministic synthetic workloads with bounded inputs. Never accept shell commands, scripts, OCI images or arbitrary binaries for host execution. VM isolation is M5, following the milestone list where section 6.2 conflicts.

## Consequences and current limitations

M5 requires independent review; GPU support remains off for unreviewed configurations.
