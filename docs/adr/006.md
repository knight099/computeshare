# ADR-006: OIDC PKCE and device keys

Status: accepted for staged implementation.

## Decision

Console and Linux CLI use OIDC Authorization Code with S256 PKCE. API verifies issuer, audience, signature, expiry and role claims. Devices enroll an Ed25519 key with owner authentication and consent; one-use 60-second challenges yield hashed, opaque 300-second credentials.

## Consequences and current limitations

Console access tokens live only in memory. CLI login tokens are 0600 and deleted after enrollment. M4 must add OS-backed credential storage and release signing.
