# Security

This is an enrollment preview, not a production compute network. No arbitrary workload execution or GPU capability is enabled.

Report vulnerabilities privately through GitHub's private vulnerability reporting feature if enabled. Otherwise contact the maintainer privately using the contact method on their GitHub profile; do not post exploit details or secrets in public issues. Operators must publish their own security/support contact before distribution.

Read `docs/threat-model.md`. Security-gated runtime features require independent review before enablement. No response-time SLA or supported production release is currently offered.
