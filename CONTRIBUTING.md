# Contributing

Read the master specification, implementation checklist, ADRs and threat model. Keep changes scoped to a milestone and include test evidence, run commands and limitations. Do not weaken authentication, consent, local Stop, isolation or settlement uniqueness for demos.

Run `make lint`, `make typecheck`, `make test`, `make build`, and relevant integration/E2E checks. Use additive, migration-safe v1 changes; incompatible public API or protocol changes require a new version and an ADR. Released agent compatibility and rollout policies are M4 work.

Contributions use the Developer Certificate of Origin 1.1: add `Signed-off-by` to commits (`git commit -s`) only when you can truthfully certify the contribution. No CLA is required. Do not fabricate third-party sign-offs. Framework code is Apache-2.0; dependencies retain their licenses.
